# Hands-off plugin marketplace

The [Hands-off](https://handsoff.inventora.digital) agent plugin: it connects your AI to Hands-off (MCP with OAuth) and keeps your project's decisions, pages, rules, components and ideas up to date while you work.

```bash
claude plugin marketplace add victorassisalves/hands-off-plugin
```

```bash
claude plugin install hands-off@hands-off
```

Details, and what the plugin sends and where: [plugins/hands-off/README.md](plugins/hands-off/README.md).

This repository is published from the Hands-off source; changes made here directly are overwritten.
